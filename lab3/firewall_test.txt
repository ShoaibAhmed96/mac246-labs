ADDITIONAL DEFENSE-IN-DEPTH RULE

iptables -A INPUT -m conntrack --ctstate INVALID -j DROP

Explanation:
This rule would help block packets with invalid connection-tracking states. It should be placed before general allow rules so invalid packets are rejected early.

CONCLUSION

The proposed five-rule ACL is designed to allow only necessary services while denying unauthorized inbound access. The six paper-based tests represent the intended policy behavior. The rules were not executed on the Kali Linux machine.

NOTE
