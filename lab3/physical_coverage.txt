DETECTIVE COVERAGE GAP

Weakness: The locked door is a preventive control, but the facility description does not identify a dedicated camera, door alarm, or independent monitoring system for the server room.

EVIDENCE PLAN
Check the server-room access records, CCTV coverage map, door alarm configuration, and physical security inspection records. Verify whether any detection system actually monitors or records entry at this door. Missing records alone are not proof that monitoring is absent.

PROPOSED COMPENSATING CONTROL
Install a CCTV camera covering the server-room entrance and require periodic footage review. This would provide additional detective coverage and help investigate unauthorized entry.
